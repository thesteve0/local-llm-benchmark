The central difference lies in how each model represents and processes sequence information. Transformers rely on self-attention, which explicitly compares every token with every other token. In a Transformer, each token is represented by a vector embedding, and the model applies multi-head self-attention. For a sequence of length n, attention computes a matrix of pairwise scores between query and key vectors, applies a softmax normalization, and then combines value vectors. This operation is often written as Attention(Q,K,V)=softmax(QK^T/sqrt(d))V. The attention matrix has size n by n, so the standard computational complexity is O(n^2) with respect to sequence length, and memory usage is also quadratic unless approximations or sparse attention are used. This quadratic cost is one reason long-context Transformers require substantial compute and memory, even when using optimizations such as FlashAttention, which reduce constant factors but do not change the asymptotic complexity.

State space models take a different route. They are inspired by continuous-time state space equations, which describe how a hidden state evolves over time. In discrete form, an SSM can be viewed as a recurrence: h_t = A h_{t-1} + B x_t, y_t = C h_t + D x_t, where x_t is the input at time t, h_t is the hidden state, and y_t is the output. The parameters A, B, C, and D define how information is propagated and transformed. Mamba improves on earlier SSMs by making these parameters input-dependent, allowing the model to adaptively control what information is retained or discarded. This selective mechanism is important for language modeling, where the relevance of past tokens can vary depending on context.

The computational implications are significant. This linear scaling makes SSMs attractive for very long sequences, because the cost grows proportionally rather than quadratically. However, sequential processing can limit parallelism during training. Mamba addresses this by using a parallel scan algorithm, which computes the recurrent state in parallel over the sequence. This preserves the linear complexity while enabling efficient training on modern hardware. The practical implications for long-context window processing are substantial. ## Response

Large language models (LLMs) are typically built on the Transformer architecture, but recent state space models (SSMs), such as Mamba, offer an alternative. The central difference lies in how each model represents and processes sequence information. Transformers rely on self-attention, which explicitly compares every token with every other token. SSMs instead maintain a compressed recurrent state that is updated as tokens are processed, allowing them to model long-range dependencies without pairwise token interactions.

In a Transformer, each token is represented by a vector embedding, and the model applies multi-head self-attention. For a sequence of length n, attention computes a matrix of pairwise scores between query and key vectors, applies a softmax normalization, and then combines value vectors. This operation is often written as Attention(Q,K,V)=softmax(QK^T/sqrt(d))V. The attention matrix has size n by n, so the standard computational complexity is O(n^2) with respect to sequence length, and memory usage is also quadratic unless approximations or sparse attention are used. This quadratic cost is one reason long-context Transformers require substantial compute and memory, even when using optimizations such as FlashAttention, which reduce constant factors but do not change the asymptotic complexity.

State space models take a different route. They are inspired by continuous-time state space equations, which describe how a hidden state evolves over time. In discrete form, an SSM can be viewed as a recurrence: h_t = A h_{t-1} + B x_t, y_t = C h_t + D x_t, where x_t is the input at time t, h_t is the hidden state, and y_t is the output. The parameters A, B, C, and D define how information is propagated and transformed. Mamba improves on earlier SSMs by making these parameters input-dependent, allowing the model to adaptively control what information is retained or discarded. This selective mechanism is important for language modeling, where the relevance of past tokens can vary depending on context.

The computational implications are significant. A standard SSM processes tokens sequentially, with each step requiring O(1) work relative to sequence length, giving O(n) time complexity for a sequence of length n. This linear scaling makes SSMs attractive for very long sequences, because the cost grows proportionally rather than quadratically. However, sequential processing can limit parallelism during training. Mamba addresses this by using a parallel scan algorithm, which computes the recurrent state in parallel over the sequence. This preserves the linear complexity while enabling efficient training on modern hardware. Inference can also be efficient because the model only needs to maintain a fixed-size hidden state, rather than storing all previous token representations.

The practical implications for long-context window processing are substantial. Transformers can access any previous token directly through attention, which gives them strong in-context retrieval capabilities. If a model needs to find a specific fact buried in a long document, attention can, in principle, locate it by assigning high weight to the relevant token. This explicit access is a major advantage for tasks requiring precise recall over long contexts. SSMs, by contrast, compress history into a fixed-size state. This compression is efficient, but it can make exact retrieval more difficult because older information may be partially overwritten or blended into the state. Mamba’s selective mechanism mitigates this problem by allowing the model to emphasize important tokens, but it does not provide the same direct token-to-token access as attention.

Another practical difference is memory behavior. A Transformer’s attention cache, often called the key-value cache, grows linearly with sequence length during inference, because the model must store keys and values for all previous tokens. This makes very long contexts memory-intensive. An SSM maintains a constant-size state, so its memory footprint does not grow with sequence length in the same way. This can be advantageous for streaming or long-running generation, where the model must process many tokens without storing the entire history.

Despite these advantages, SSMs are still a relatively new class of architectures. Transformers benefit from a mature ecosystem, extensive empirical validation, and strong performance across many tasks. Mamba and related models show promising results, especially in long-sequence modeling, but they may require careful design to match the retrieval and reasoning strengths of attention. Some hybrid approaches combine attention and SSM layers, using attention for precise access and SSMs for efficient long-range modeling.

In summary, Transformers and state space models represent two different strategies for sequence modeling. Transformers use explicit self-attention, yielding strong direct access to past tokens but quadratic computational and memory costs. SSMs such as Mamba use recurrent state updates with selective, input-dependent dynamics, yielding linear complexity and constant-size memory, but with a more compressed representation of history. For long-context processing, the choice between them depends on the trade-off between precise retrieval and efficient scaling. Transformers are well suited when direct access to distant tokens is critical, while SSMs are attractive when sequence length is very large and computational efficiency is a priority.
