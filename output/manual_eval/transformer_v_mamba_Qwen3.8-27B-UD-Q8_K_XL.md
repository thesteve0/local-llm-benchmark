Attention scores are computed by multiplying queries with keys, usually after scaling and masking, and then applying softmax. The resulting weights are used to aggregate values. This mechanism is powerful because it allows a token to attend directly to any previous or future token, depending on the mask. It also supports parallel training, since all pairwise scores for a sequence can be computed simultaneously. However, the cost of this flexibility grows with sequence length. For a sequence of length n, standard self-attention requires O(n^2) operations and O(n^2) memory to store the attention matrix. Even with optimizations such as FlashAttention, which reduces memory traffic and improves practical efficiency, the fundamental quadratic dependence on n remains. As a result, long-context Transformers become expensive in both compute and memory, and inference latency can increase substantially when the context window grows.

In discrete form, an SSM can be written as h_t = A h_{t-1} + B x_t and y_t = C h_t + D x_t, where x_t is the input at time t, h_t is the hidden state, and y_t is the output. The matrices A, B, and C define how information is propagated and filtered. Mamba extends this idea with selective mechanisms: the parameters can depend on the input, allowing the model to decide what information to retain or discard. This selectivity is important for language, where relevant context may be sparse and distant.

## Response

Large language models (LLMs) are typically built on the Transformer architecture, but recent state space models (SSMs), such as Mamba, offer an alternative. The central difference lies in how each model represents and processes sequence information. Transformers rely on self-attention, which explicitly compares every token with every other token. SSMs instead maintain a compressed recurrent state that is updated as tokens are processed, allowing them to model long-range dependencies without pairwise token interactions.

In a Transformer, each token embedding is projected into query, key, and value vectors. Attention scores are computed by multiplying queries with keys, usually after scaling and masking, and then applying softmax. The resulting weights are used to aggregate values. This mechanism is powerful because it allows a token to attend directly to any previous or future token, depending on the mask. It also supports parallel training, since all pairwise scores for a sequence can be computed simultaneously. However, the cost of this flexibility grows with sequence length. For a sequence of length n, standard self-attention requires O(n²) operations and O(n²) memory to store the attention matrix. Even with optimizations such as FlashAttention, which reduces memory traffic and improves practical efficiency, the fundamental quadratic dependence on n remains. As a result, long-context Transformers become expensive in both compute and memory, and inference latency can increase substantially when the context window grows.

State space models take a different route. They are inspired by continuous-time state space equations, which describe how a hidden state evolves over time under input signals. In discrete form, an SSM can be written as h_t = A h_{t-1} + B x_t and y_t = C h_t + D x_t, where x_t is the input at time t, h_t is the hidden state, and y_t is the output. The matrices A, B, and C define how information is propagated and filtered. Mamba extends this idea with selective mechanisms: the parameters can depend on the input, allowing the model to decide what information to retain or discard. This selectivity is important for language, where relevant context may be sparse and distant.

The computational profile of SSMs is different. During inference, an SSM processes tokens sequentially and updates a fixed-size state, giving O(1) cost per new token and O(n) total cost for a sequence of length n. During training, SSMs can be converted into a convolutional form, enabling parallel computation over the sequence. Mamba in particular uses hardware-aware parallel scanning to achieve efficient training while preserving the recurrent interpretation. Thus, SSMs avoid the explicit O(n²) attention matrix and can scale more gracefully to very long sequences.

The practical implications for long-context processing are significant. Transformers are highly effective at retrieving specific information from long contexts because attention can directly link a query token to a relevant token. This makes them strong on tasks requiring exact recall, such as needle-in-a-haystack tests. However, as context length increases, the quadratic cost can limit deployment, especially on consumer hardware or in latency-sensitive applications. SSMs, by contrast, are attractive for long sequences because their inference cost grows linearly and their memory footprint remains bounded by the state size. They can process long documents, streams, or conversations without storing all previous tokens in an attention cache. The tradeoff is that SSMs may be less precise at retrieving rare or distant facts if the relevant information has been compressed or forgotten in the state. Selective SSMs mitigate this issue, but they do not provide the same explicit, token-to-token lookup mechanism as attention.

In an introductory course, the key takeaway is that Transformers and SSMs represent two different strategies for sequence modeling. Transformers use explicit attention to create dense, pairwise relationships among tokens, yielding strong expressivity and direct retrieval at the cost of quadratic complexity. SSMs use a recurrent, state-based representation that summarizes the past in a fixed-size vector, yielding linear-time inference and better scalability for long contexts, but with a different inductive bias and potentially weaker exact recall. Modern architectures may combine these ideas, using attention for local or selective retrieval and SSMs for efficient long-range propagation. Understanding these differences helps explain why model choice matters when designing systems for short, precise tasks versus long, streaming, or memory-constrained applications.
